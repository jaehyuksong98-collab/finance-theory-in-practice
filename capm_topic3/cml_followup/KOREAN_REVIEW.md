# 검토 요약 — CAPM 강의의 최적 포트폴리오와 자본시장선

- **핵심 주장:** 과거 10년 수익률로 샤프비율이 가장 높아 보이는 조합을 선택해도, 다음 해의 위험조정 성과가 단순 동일비중보다 확실히 높다고 말할 수 없었다. 1973년 7월–2026년 6월, 53개 연속 평가연도에서 선택 전략 샤프 0.431, 동일비중 0.492, 미국 시장 대용 지표 0.504. 선택–동일비중 차이 −0.062의 연도 블록 부트스트랩 95% 구간은 [−0.246, +0.114]로 0을 포함한다.
- **경제적 이유:** 효율적 경계와 자본시장선은 기대수익률·위험이 알려진 이론 모형이다. 현실에서는 이를 과거 표본으로 추정해야 하므로 표본오차가 생긴다. ‘최적’은 자산집합·추정기간·제약·목적함수에 조건부다. 선택 전략의 평균 초과수익률은 5.67%, 동일비중은 8.54%지만 변동성도 각각 13.16%, 17.35%로 다르므로 평균수익률만으로 최적화 성패를 판단하지 않는다.
- **산식·범위:** 월별 초과수익률 `Σwᵢ(Rᵢ−RF)`. 연율화 산술평균은 월평균×12, 변동성은 월 표본표준편차×√12, 샤프는 두 값의 비율. 세 개의 미국 베타순위 주식 포트폴리오 그룹(낮음·중간·높음), 매년 직전 120개월 학습 후 다음 12개월 평가, 공매도·차입 없음. 데이터는 Fama/French 202608 CRSP 스냅샷, 2026년 10월 17일 다운로드. 5/10/15년 추정기간을 공통 1978년 7월–2026년 6월에 비교하면 선택 샤프가 0.490/0.504/0.605, 동일비중은 0.527로 결론이 설정에 민감하다.
- **AI·코드와 사람의 역할:** Python은 공식 원본 ZIP의 월별 값을 파싱하고 후보 비중 5,151개를 검색하며 날짜 겹침·월 개수·원본 해시를 검사한다. 사람은 Fama/French의 포트폴리오 정의, 수정 이력, 거래 가능성, 결과 해석과 공개 전 수치·차트·출처를 검토한다. 2025년 7월 원본 행에서 선택 초과수익률 −1.516%를 별도로 검산했다.
- **리포트 구성:** 질문과 이론 구분, 원자료·정의, 학습/평가 설계, 결과·불확실성, 추정기간 민감도, 실무 해석·한계·재현법.
- **한계:** 이 차트는 세 주식 포트폴리오의 부분집합 경계이지 완전한 시장 포트폴리오의 CML이 아니다. 예상수익률·투자자 선호를 직접 관찰하지 못한다. 앞선 CAPM 분석 후 세 자산군을 선택한 탐색적 후속 연구이므로 전체 역사에 대해 사전등록·블라인드 설계가 아니었다. 각 연도 선택 알고리즘 자체는 미래 연도 수치를 사용하지 않는다. 역사적 포트폴리오는 실제 거래 펀드가 아니며 비용·세금·회전율을 빼고 계산했다. 2026년판 역사 자료는 이후 수정될 수 있다. 중첩 학습기간과 자산 선택 때문에 부트스트랩 구간은 설명용이고 인과적 증거가 아니다. 현재 GitHub 후속 폴더·Article은 **초안이며 아직 게시하지 않았다**.
