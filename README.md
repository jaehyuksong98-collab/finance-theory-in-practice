# Finance Theory in Practice

I use this series to test ideas learned in Corporate Finance and Investment Analysis against documented market observations. Each project records the theory, sample, original sources, calculations, limitations and a workflow for adding later results.

## Projects

1. [Ex-dividend prices: a Microsoft pilot](ex_dividend_msft/README.md) - four ordinary cash dividends, November 2025 to August 2026. Includes the event CSV, Python calculations, a comparison chart, a two-page methods report and an English LinkedIn article draft.

The first project is deliberately descriptive. It does not estimate a market-wide or causal effect. Course lecture files are not redistributed here.

## Reproducibility

See each project README for its source URLs, price conventions, commands and checks. New data should be reviewed against the issuer announcement and a documented price source before being added. Historical revisions are stored as snapshots rather than silently overwriting earlier inputs.
